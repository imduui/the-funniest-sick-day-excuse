One line, under 200 characters, that someone could send to call in sick — the funniest excuse in one breath. An entry for [The Funniest Sick-Day Excuse](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) on [make.fun](https://make.fun).

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt`.

## The line

> Can't come in — I woke up sounding exactly like our CEO, so legal says I have to stay home until my real voice comes back.
